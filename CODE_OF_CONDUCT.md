# Code de conduite

## Notre engagement

Nous nous engageons à faire de la participation à ce projet une expérience respectueuse et
sans harcèlement pour tout le monde, quel que soit le niveau d'expérience, l'identité ou
l'origine.

## Nos standards

Comportements attendus :

- Faire preuve d'empathie et de respect envers les autres contributeurs.
- Accepter les critiques constructives avec ouverture.
- Se concentrer sur ce qui est le mieux pour le projet.

Comportements inacceptables :

- Propos ou comportements harcelants, discriminatoires ou insultants.
- Publication d'informations privées d'autrui sans consentement.

## Application

Les cas de comportement abusif peuvent être signalés au mainteneur du projet (contact à
définir par projet dérivé). Toute plainte sera examinée et traitée de manière appropriée.

Adapté du [Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.
