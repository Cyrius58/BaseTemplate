# 1. Enregistrer les décisions d'architecture

Date : 2026-09-02

## Statut

Accepté

## Contexte

Nous avons besoin d'enregistrer les décisions d'architecture prises dans ce projet.

## Décision

Nous utiliserons des Architecture Decision Records (ADR), tels que décrits par Michael Nygard,
stockés dans `docs/adr/`. Un nouveau fichier `NNNN-titre-court.md` est créé pour chaque décision
structurante (choix technologique, changement d'architecture, dépréciation...).

## Conséquences

L'historique des choix techniques est traçable et justifié pour les contributeurs futurs.
